Algorithmic Playground

Real-Time Detection Methods

🔢 Parity Check (1D & 2D)

1-D Parity: Counts '1' bits to ensure parity value. Fast but misses even-number bit corruptions.

2-D Parity (Block): Places data in grid format, computing parity for both rows and columns. Easily detects multiple bit corruptions.

⚡ Checksum & CRC-8

Checksum: Computes 1's complement arithmetic sum over grouped binary blocks. Extensively utilized in TCP and IP headers.

CRC-8 (Cyclic Codes): Modulo-2 binary polynomial division (`100000111`). Strong burst-error protection used in hard drives, USBs, and Ethernet.

Context

How USB Drives Detect Failures

"Cosmic rays, voltage shifts, or standard wear-and-tear can quietly flip data bits during writes."

Our application replicates this! When a file writes, the device calculates a **CRC checksum** and saves it. When read, the device re-calculates the CRC checksum. If they match, the file is perfectly fine. If they don't match, you get a file corruption error.
