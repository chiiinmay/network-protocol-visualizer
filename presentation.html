Error Detection

The Playground Algorithms


1D Parity (Even)

Counts total number of 1-bits. Appends a parity bit to make count even. Simple & fast but fails on even-number bit errors (false negatives).


Example: 1101 → parity=1 → Send 11011

2D Parity (Block)

Computes parity for every row AND column. Can detect all 1, 2, and 3-bit errors. Much stronger than 1D parity.


Use case: Early disk storage systems

Checksum (8-bit)

Divides data into 8-bit blocks and sums them. Takes the 1's complement as the checksum. Used in IP, TCP, and UDP headers.


Use case: TCP/IP networking

CRC-8 (Cyclic)

Performs polynomial (modulo-2) division of data using generator polynomial 100000111. Extremely robust — detects burst errors.


Use case: USB, Ethernet, file systems

Why It Matters

"How does my USB know my file got corrupted?"


When you save a file to a USB drive, the hardware computes check bits using CRC and stores them alongside the data.

When you read the file back, it recomputes the check bits.

If they match ✅ — file is intact.
If they don't match ❌ — "The file or directory is corrupted and unreadable."
